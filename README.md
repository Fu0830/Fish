# Fish 结单小票机

基于原版 [receipt-shop](https://github.com/Fu0830/receipt-shop) 复制改造的**独立定制版**，与原版及其他版本互不影响。

## 定制内容

- 俱乐部名称：**结单小票机**（FISH）
- 盖章署名：**小鱼**（FISH），固定显示、不可关闭
- 每一项陪陪均可填写**陪陪结单备注**，备注显示在小票对应单项下方；不填则不显示
- 票面角色图支持**上传自定义头像**（自动压缩保存到本地，可一键恢复默认角色）
- 站点配有打印机图标（favicon / 桌面主屏图标 / manifest），可“添加到主屏幕/桌面”
- 独立本地存储键：`fish-v1`，与其他版本存档互不串

## 本地预览

直接用浏览器打开 `index.html` 即可。
